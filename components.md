Here's the trimmed, prioritized list — these 25 cover the patterns that show up again and again in tier-2 product company interviews. I've ranked by how frequently they're asked.

**Must-do (asked constantly — do these first)**
1. Debounced Search Bar with API call
2. Todo App with filters (all/active/completed)
3. Shopping Cart (add/remove/quantity/discount/total)
4. Accordion (single + multi-open variants)
5. Autocomplete/Typeahead with keyboard navigation
6. Star Rating component
7. Modal/Dialog (reusable, escape/click-outside close)
8. Pagination (client-side + "load more")
9. Infinite Scroll
10. Tabs component

**High-frequency**
11. Nested Comments (recursive, reply-at-any-depth)
12. Multi-step Form Wizard with validation
13. File Explorer (nested folders, expand/collapse)
14. Tic-Tac-Toe with undo/redo
15. OTP Input (auto-focus next box, paste support)
16. Image Carousel/Slider (auto-play, manual nav)
17. Dropdown/Select with search
18. Toast/Notification system (queue, auto-dismiss)
19. Progress Bar / Stepper (multi-stage upload or process)
20. Table with sorting + column filtering

**Good to have (show up often enough to prep)**
21. Kanban Board (drag-drop between columns)
22. Rate Limiter / disable-button-to-prevent-spam-click
23. Calendar/Date Picker (basic month view + date select)
24. Chat UI (message list, auto-scroll to bottom, send on enter)
25. Poll/Voting component (real-time-ish vote count update)

**Priority order to practice:** Do #1–10 cold — these alone cover most rounds. Once solid, move to #11–20. The last 5 are lower-frequency but round out your prep if you have extra time before interviews start.

One thing worth flagging: don't just build these once and move on — re-build 2-3 of the must-do ones from scratch a second time a week later, without looking at your old code. That's what actually tells you if you've internalized the pattern or just remember your own solution.
