## Good Interview Questions to Practice

- [ ] How do you handle sparse arrays in `map`, `filter`, and `forEach`?
- [ ] What should happen if `reduce` is called without an `initialValue`?
- [ ] How do you preserve `this` inside a custom `bind`, `debounce`, or `throttle`?
- [ ] How do you implement `throttle` so it supports both leading and trailing execution?
- [ ] How do you make `memoize` work with multiple arguments and object arguments?
- [ ] How do you implement `deep clone` without getting stuck on circular references?
- [ ] How is `Promise.allSettled` different from `Promise.all` in failure behavior?
- [ ] How would you make `compose` and `pipe` support any number of functions?
- [ ] How do you dedupe arrays by value and by object property?
- [ ] How would you implement `groupBy` in a way that preserves original ordering?
- [ ] How do you implement `flat` and `flatMap` without using built-in flattening helpers?
- [ ] What are the edge cases in `Object.assign` with getters, symbols, and `null`/`undefined` sources?
- [ ] How would you test a polyfill quickly with a minimal runnable snippet?
